## 动效清单（网页端）

| 效果        | 说明                                                           |
| --------- | ------------------------------------------------------------ |
| 逐字入场      | 标题与水印按字符 26ms 递增淡入，仅屏幕端                                      |
| 遮片揭示      | 图片从下往上揭开（clip-path）                                          |
| Ken Burns | 项目封面缓慢推近（18s）                                                |
| 光标光晕      | 跟随鼠标的柔光，带缓动                                                  |
| 章节圆点      | 右侧 23 个圆点，当前页高亮，可点击跳转                                        |
| 磁性 hover  | 标签随指针微位移                                                     |
| 视差        | 封面巨型水印随滚动位移                                                  |
| 颗粒        | 低透明度动态颗粒层（仅屏幕）                                               |
| 缓动        | 全部使用 `cubic-bezier(.2,.7,.2,1)`，并支持 `prefers-reduced-motion` |

> 所有屏幕端特效在 `@media print` 中自动关闭，导出的 PDF 保持干净。

## 部署到 GitHub Pages

1. 新建仓库，上传本目录全部文件（**必须带 `.nojekyll`**）
2. Settings → Pages → Source: `main` / `/ (root)` → Save
3. 访问 `https://<用户名>.github.io/<仓库名>/`

```bash
git init && git add . && git commit -m "portfolio: AI short video director 2027"
git branch -M main && git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```
